# Auto-Translate-to-News

CS2 赛后采访自动翻译的本地服务：音频 → Whisper 转写 → LLM 两段式翻译润色 → 名词规范化 → Word 初稿 → 飞书发送，人工精校出终稿。

设计文档：[docs/superpowers/specs/2026-10-29-live-interview-pipeline-design.md](docs/superpowers/specs/2026-10-29-live-interview-pipeline-design.md)

从预约比赛到交稿全自动：

1. 「比赛」页列出 HLTV 未来 5 天的比赛，人工挑选预约；预约时抓取比赛当时的阵容、BP、比分、近期战绩、图池、新闻。
2. 开赛前开始监视比分，决胜图接近结束时自动录制官方直播（Twitch / YouTube / Kick），边录边转写。
3. 比赛结束后由 LLM 在滚动转写里定位赛后采访，采访结束后自动截取，走完转写 → 翻译润色 → Word → 飞书。
4. 飞书群里每场比赛只有一张进度卡片，随状态自动更新；需要人处理的事回复在卡片下面。常用操作直接点卡片上的按钮；自动判断不准时，在任务页手动标注采访起止即可。

也可以手动提供采访音频（上传文件或视频链接）。

## 环境要求

- Python 3.10+
- Node.js 20+（只用于构建前端）
- ffmpeg（在 PATH 中，或在设置页填写路径）
- Google Chrome（访问 HLTV 用；通过 Playwright 驱动本机 Chrome，不需要另外下载浏览器）
- streamlink（`pip install -r requirements.txt` 会装上，录直播用）
- NVIDIA GPU（推荐）。faster-whisper 使用 CTranslate2 自带的 CUDA 支持，需要 CUDA 12 的 cuBLAS 和 cuDNN 9；不可用时会自动退回 CPU。

## 安装

```bash
pip install -r requirements.txt
```

```bash

```

```bash
npm run build
```

Whisper 模型：把 faster-whisper 格式的模型放在 `models/whisper/`（含 `model.bin`），或在设置页直接填写模型名（如 `large-v3`、`large-v3-turbo`），首次运行会自动下载。

说话人分离模型（推荐本地）：把 pyannote `speaker-diarization-3.1` 的 `config.yaml` 以及 `segmentation-3.0`、`wespeaker-voxceleb-resnet34-LM` 两个 `pytorch_model.bin` 放进 `models/pyannote/speaker-diarization-3.1/`，并把 `config.yaml` 里的两个模型改成本地文件的绝对路径，然后在设置页填写该目录。

## 首次配置（设置页）

1. **代理**：默认 `http://127.0.0.1:7897`，HLTV、视频下载、LLM 共用；飞书始终直连。
   访问 HLTV 时会弹出一个 Chrome 窗口（空闲 10 分钟自动关闭）。Cloudflare 验证一般 20 秒左右自动通过；偶尔需要人工点击时会发飞书提醒，在窗口里点一下即可。
2. **LLM**：添加自定义供应商（OpenAI 兼容或 Anthropic 兼容，填写 Base URL、API Key、模型），点「测试连接」确认可用，然后为「英文清洗」和「中文成稿」两步分别选择供应商。「直播采访定位」每 30 秒调用一次，可以单独选一个响应快的模型，不选就用英文清洗的。
3. **直播监视与录制**：比分数据源默认 bo3.gg 优先、失败时用 HLTV；决胜图领先方到 10 分开始录（bo3.gg 没有回合比分时改从 HLTV 比分板读；也读不到就在决胜图开打 15 分钟后录）；比赛结束后 30 分钟内没发现采访就停止。一般不用改。
4. **飞书**（可选，推荐发到群聊）：填写自建应用的 App ID / App Secret，选择发送到群聊（chat_id）或个人（open_id）。在飞书开发者后台：
   - 开通机器人能力和 `im:message`、`im:resource` 权限，把应用拉进目标群。
   - 卡片按钮：「事件与回调 → 回调配置」选择 **使用长连接接收回调**，添加回调 **卡片回传交互**（`card.action.trigger`）。长连接是本地服务主动连出去的，不需要公网地址。
   - 改完权限或回调后要发布应用新版本才生效。
   - 回到设置页保存，点「发送测试卡片」：群里出现一张示例卡片，卡片下有一条话题回复；点卡片上的按钮提示「卡片按钮已连通」就配置好了。

## 使用

### 直播任务（主流程）

1. 「比赛」页找到要翻译的比赛，点「预约」，立即抓取背景信息。
2. 之后全自动，任务状态依次是：
   - **已预约** → 开赛前 15 分钟变为 **监视中**：按决胜图比分调整检查频率（10 / 5 / 2 分钟）。比分默认从 bo3.gg 的公开接口读取，读不到时自动改用 HLTV（浏览器里常开的比赛页）。
   - **录制中**：决胜图接近结束时，自动选官方直播流开始录音，每 30 秒转写一段，并让 LLM 判断采访是否开始、是否结束。
   - **采访监听中**：比赛已结束，继续录音和判断。
   - 连续两次判断都认为采访已结束后自动截取（前后各留 10 秒），停止录音，进入后处理，完成后状态为 **待精校**，Word 发到卡片的话题里。实测采访结束后 3～5 分钟出初稿；超过 15 分钟没出会提醒。
   - 比赛结束 10 分钟没发现采访会提醒，30 分钟没发现就判定 **无采访** 并停止录音。
   - 所有比分数据源都读不到时会提醒；开赛后持续读不到 10 分钟，直接开始录制。
3. 任务页「直播」标签可以随时介入：
   - 看实时比分、各图结果、比分来源、下次检查时间，或「立即检查」。bo3.gg 自动匹配错了可以「手动指定」比赛链接。
   - 换直播源（从列表选，或填链接），或「立即开始录制」。
   - 「比赛已结束」：比分数据源都不可用时，人工确认比赛结束。
   - 在滚动转写里悬停一行「设为起点 / 设为终点」，「试听」确认后「截取并开始处理」。自动定位不准、或已判定无采访但其实有采访时都用这个。
   - 「本场无采访」「取消预约」。
4. 服务重启后，正在录制的任务会自动接着录。

### 飞书卡片

启用飞书后，每个任务（预约的比赛、新建的任务）在群里有且只有一张卡片：

- 标题栏颜色和标签表示当前状态，下面是进度（预约 → 监视 → 录制 → 采访 → 初稿 → 精校）、比分和各图结果、直播源、采访位置、处理进度、最近三条动态。
- 卡片随状态自动更新，**更新不会提醒**。比赛开始、开始录制、比赛结束、检测到采访、采访已截取这类进展只体现在卡片上。
- **需要人处理的事以话题回复在卡片下面，会提醒**：找不到直播源、直播源是回放、录制异常、比分数据源不可用、尚未发现采访 / 判定无采访、采访定位失败、初稿超时、处理失败、初稿就绪（附 Word）。
- 按钮随状态变化：立即检查、立即录制、取消预约、比赛已结束、本场无采访、重新录制、从失败处重试、标记完成；录制相关状态下可以在卡片里填直播链接直接开录或换源。「打开任务页」需要在运行服务的电脑上打开。
- 飞书只允许修改 14 天内发出的卡片，过期后会重新发一张。服务启动时，正在进行中的任务如果还没有卡片会补发。

### 手动任务

「任务」页新建任务：填 HLTV 比赛链接（推荐，阵容以比赛当时为准）或两支队伍名，选择视频链接或上传本地文件；视频较长时可以填写截取的起止时间。直播任务也可以在「任务信息」里直接上传采访音频。

### 查看和修改结果

流水线：抓取背景信息 → 获取音频 → 语音转写 → 英文清洗 → 中文成稿 → 生成 Word → 飞书发送。任务详情页可以看和改每一步的结果：

- **中文稿**：修改后点「保存并重新生成 Word」。
- **英文清洗稿**：修改后点「保存并重新翻译」。
- **背景信息**：队名、阵容、教练就是稿件的规范写法，抓取失败或不全时在这里补；也能看到排名、近期战绩、图池和新闻。
- **名词报告**：自动替换了哪些名字，哪些需要人工核对。
- 任意阶段失败后，可以选择从该阶段重跑。

下载 Word（或在飞书卡片的话题里接收），精校后点「标记完成」（任务页或卡片上都可以）。

### 稿件格式

- `Q：` 开头的主持人问题整段加粗；`A：` 开头的选手回答不加粗。
- 全文小四（12pt），A4，字体为 Word 默认。

### 专有名词

选手名、战队名必须与 HLTV 完全一致（如 `m0NESY`、`ZywOo`），通过三层保证：

1. 阵容写入 Whisper 提示词，提高识别率。
2. LLM 两步都附带规范名表。
3. 成稿后逐级替换：拼写变体（`monesy`、`Mo Nesy`、`Zywo0`）直接归一；发音相近的（`Monessy`、`Manasi`）按发音推断；剩下的结合上下文交给 LLM 判断（如 `Shearer` → `sh1ro`）。推断出的替换在名词报告里标黄，推断不出的列入待核对。

「术语表」页可以添加别名（如 `NAVI → Natus Vincere`、`小蜜蜂 → Vitality`）和术语的固定译法。

## 数据

所有数据都在 `data/` 目录下（可用环境变量 `ATN_DATA_DIR` 修改）：

- `app.db`：任务、日志、术语表、设置
- `tasks/<id>/`：每个任务的音频、转写、各步中间稿、提示词和 Word 文件；直播任务还有 `chunks/`（录音分段）、`live_transcript.jsonl`（滚动转写）、`live.json`（比分快照、直播源、采访定位结果）、`interview.wav`（截取的采访）、`recorder.log`
- `browser-profile/`：访问 HLTV 用的 Chrome 配置（保存 Cloudflare 验证状态）
